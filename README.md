# AutoDetail Pro — Premium Redesign

A luxury automotive detailing **portfolio concept** built with HTML, CSS, and vanilla JavaScript.

## Features
- Black-and-gold cinematic visual direction inspired by a supplied reference
- Responsive hero artwork, service cards, package pricing, and gallery
- Accessible mobile navigation and local-only demo contact form
- No framework or build process required

## Run
Open `index.html` in a browser.

## Deploy
Upload `index.html`, `style.css`, `script.js`, `favicon.svg`, and `hero-car.webp` to the **root** of the existing `autodetail-pro` GitHub repository. Enable GitHub Pages on `main` / `(root)` if not already enabled.

## Important
AutoDetail Pro is fictional. Pricing, services and business information are examples, not real offers. The form **does not send or store messages**. The image is AI-generated concept artwork, not a photo of a real studio or customer vehicle. No real endorsements or ratings are claimed.

Fonts load from Google Fonts when online, with local fallbacks.
